# Developing RADIANT

Evidence-based pro-nuclear advocacy site, adapted from my paper "Radiant: The Case
for Nuclear Energy". One self-contained page, no build step, no package manager.
See @README.md for deployment and sourcing.

## Run it

```bash
python3 -m http.server 4174
```

Then open http://localhost:4174. There is nothing to install and nothing to build.

## Gotchas

- **Every statistic on the page is cited to a primary source** (EIA, IPCC, UNECE,
  NRC, DOE, UNSCEAR, BLS, Our World in Data, NEI, IAEA) in a numbered reference
  list. Adding a number without adding its citation breaks the entire premise of
  the site. Never estimate, round, or "approximately" a figure that has a source.
- **Advocacy, not neutrality, but honest.** The case is made with real numbers and
  acknowledged tradeoffs. Do not overclaim, and do not soften a genuine downside.
- The design is deliberately sharp and editorial: large type, high contrast, a
  motion system built on GSAP + Lenis. All libraries are vendored under `assets/`,
  self-hosted with the fonts. Keep it that way; no CDN links.
- `news.json` is generated by `scripts/update_news.py`. Edit the script, not the
  JSON.
- Deploys from GitHub Pages, `main` branch root, to deswo.github.io/RADIANT. I push
  through GitHub Desktop, so leave committing and pushing to me unless I ask.

## Layout

```
index.html               the entire site
assets/fonts/            self-hosted faces
assets/*.min.js          vendored GSAP, ScrollTrigger, SplitText, DrawSVG, Lenis
assets/plant*, *.mp4     hero media
news.json                generated feed
scripts/update_news.py   the generator
ROADMAP.md               what is planned next
```
