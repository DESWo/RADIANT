# Developing RADIANT

Evidence-based pro-nuclear advocacy site, adapted from my paper "Radiant: The Case
for Nuclear Energy". One page, no build step, no frameworks, no runtime
dependencies; the code is split across `css/`, `js/`, and `data/` as plain ES
modules. See @README.md for deployment and sourcing, and @DESIGN.md for how
the museum is put together.

## Run it

```bash
npm run serve
```

Then open http://localhost:4174. The site itself needs nothing installed and
nothing built; `npm` is only there for the tests.

## Test it

```bash
npm install   # once: Playwright, the only dev dependency
npm test
```

Five suites, about nine minutes. `npm test -- static models` runs the
no-browser checks (markup, citations, and both models unit-tested) alone and
finishes in about a second, which catches most mistakes.

The same command runs in CI on every push. If a check fails, read what it
compared: the physics suites assert against closed-form results and a
Runge–Kutta reference, so a failure there means the model changed, not that
the test drifted.

## Gotchas

- **Every statistic on the page is cited to a primary source** (EIA, IPCC, UNECE,
  NRC, DOE, UNSCEAR, BLS, Our World in Data, NEI, IAEA) in a numbered reference
  list. Adding a number without adding its citation breaks the entire premise of
  the site. Never estimate, round, or "approximately" a figure that has a source.
- **Advocacy, not neutrality, but honest.** The case is made with real numbers and
  acknowledged tradeoffs. Do not overclaim, and do not soften a genuine downside.
- The design is deliberately sharp and editorial: large type, high contrast, a
  motion system built on GSAP (core + DrawSVG). Both files are vendored under
  `assets/`, self-hosted with the fonts. Keep it that way; no CDN links.
- `news.json` is generated by `scripts/update_news.py`. Edit the script, not the
  JSON.
- Deploys from GitHub Pages, `main` branch root, to deswo.github.io/RADIANT. I push
  through GitHub Desktop, so leave committing and pushing to me unless I ask.

## Layout

```
index.html               the page: all content and markup
css/                     fonts, base, museum shell, exhibits, responsive
js/                      the runtime; main.js drives the museum,
                         reactor-model.js and grid-model.js are the physics
data/                    datasets and registries the runtime renders from
assets/fonts/            self-hosted faces
assets/*.min.js          vendored GSAP core and DrawSVG
assets/*.mp4             plant footage
tests/                   the checks; run.mjs is the entry point
news.json                generated feed
scripts/update_news.py   the generator
scripts/serve.mjs        the local static server behind npm run serve
DESIGN.md                how the museum works
ROADMAP.md               what is planned next
```
